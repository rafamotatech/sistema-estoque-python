# Sistema de Estoque em Python

Sistema de gerenciamento de estoque desenvolvido em Python, com interface gráfica e banco de dados SQLite.

Este projeto foi criado para praticar lógica de programação, desenvolvimento de interfaces e operações com banco de dados.

## Funcionalidades

- Cadastro de produtos com nome, preço e quantidade.
- Listagem dos produtos cadastrados.
- Atualização da quantidade em estoque.
- Remoção de produtos com confirmação.
- Validação dos dados informados pelo usuário.
- Armazenamento dos dados em banco de dados SQLite.

## Tecnologias utilizadas

- Python
- Tkinter
- SQLite
- Git e GitHub

## Como executar

1. Instale o Python.
2. Baixe ou clone o repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
py interface.py
```

O banco de dados e a tabela de produtos são criados automaticamente quando necessário.

## Aprendizados

- Funções e estruturas condicionais.
- Validação de dados.
- Operações CRUD: cadastrar, consultar, atualizar e remover.
- Integração entre Python e SQLite.
- Desenvolvimento de interfaces gráficas com Tkinter.
